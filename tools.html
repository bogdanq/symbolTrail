Инструменты ​

Восемь способов задать вопрос к графу кода.

Общий формат ​

Все инструменты принимают объект с обязательным queries: от одного до восьми независимых запросов одного метода. Ответ — текстовая карточка, а не JSON.

js
find({
  queries: [{ name: "foo" }, { name: "bar" }],
});
  • file — путь от корня индексированного репозитория или абсолютный путь.
  • symbol — имя объявления или экспорта в выбранном файле.
  • repo — имя участника выбранного индекса; используйте для различения репозиториев.
  • line и column — координаты с единицы, где инструмент их поддерживает.

Пути a.js, b.js и имена foo, bar ниже условные. В реальном запросе замените их адресами своего кода.

Тот же вызов можно выполнить без MCP-клиента:

sh
npm run mcp:cli -- 'find({ queries: [{ name: "foo" }] })'

find ​

Найдите точку, с которой начать исследование: по имени, позиции, фразе, ключу задачи или полному SHA коммита.

js
find({ queries: [{ name: "foo" }] });
find({ queries: [{ file: "a.js", line: 3, column: 1 }] });
find({ queries: [{ q: "parse configuration file:src/ lang:ts" }] });

Уточняющие параметры: file, repo, raw, more. Селекторы issue и sha используют индексированные Git-данные. Для issue нужен шаблон извлечения ключа из сообщений коммитов; обращения к трекеру нет.

При единственном подходящем объявлении find может сразу открыть карточку его потребителей. raw: true сохраняет исходные попадания без автоматического открытия и свёртки.

Поиск по q исключает файлы с меткой test; поиск по name включает тестовые места. Для векторной части поиска нужны векторы.

callers ​

Покажите потребителей объявления: вызовы, другие роли использования и тестовые места при наличии данных.

js
callers({ queries: [{ file: "a.js", symbol: "foo" }] });

Обязателен file. Дополнительно доступны symbol, line, repo, more. Без symbol инструмент показывает объявления файла и точки перехода к их использованию.

Тестовое место в ответе означает записанную связь с тестовым кодом. Это не результат запуска теста.

callees ​

Посмотрите, какие вызовы находятся в теле объявления и какие определения удалось связать с ними.

js
callees({ queries: [{ file: "a.js", symbol: "foo" }] });

Обязательны file и symbol. Дополнительно: line, repo, more. line помогает выбрать объявление, если имя неоднозначно, например у анонимных функций.

Неизвестная цель не подбирается по похожему имени. Определение параметра callback или поля типового контракта не доказывает конкретную реализацию во время выполнения.

map ​

Получите обзор папки или найдите область по фразе.

js
map({ queries: [{ prefix: "src" }] });
map({ queries: [{ q: "configuration loading" }] });

Нужен prefix или q; дополнительно доступны repo и more. Карточка показывает входы в область, соседей по импортам и реэкспортам, внутренние объявления и места активных изменений по Git-данным.

Используйте её, чтобы выбрать файлы для чтения. Обзор области не заменяет чтение условий внутри функций.

review ​

Сопоставьте текущий git diff HEAD с внешними потребителями изменённых или удалённых объявлений.

js
review({ queries: [{ files: ["a.js", "b.js"] }] });

Обязателен непустой массив files; дополнительно доступен repo. Файлы одного элемента queries образуют общую область проверки. Потребители внутри этой области исключаются из внешних указателей.

Инструмент возвращает сырой дифф и адреса мест для проверки. Он не выносит автоматический вердикт о безопасности изменения. Отсутствие указателя не доказывает отсутствие семантической зависимости.

shape ​

Изучите записанные формы вызовов по имени.

js
shape({ queries: [{ name: "foo" }] });
shape({ queries: [{ name: "foo", argsCount: 0 }] });
shape({ queries: [{ name: "C", isNew: true }] });

Обязателен name. Фильтры: argsCount, object, isNew, form, file, repo; продолжение — more.

argsCount считает сохранённые аргументы представления. Индекс сохраняет идентификаторы, поэтому это не универсальный счётчик всех аргументов JavaScript-вызова с литералами или spread. Проверяйте полный вызов в сниппете и исходнике.

cycles ​

Найдите циклы импортов на уровне файлов или репозиториев.

js
cycles({ queries: [{}] });
cycles({ queries: [{ file: "a.js" }] });
cycles({ queries: [{ scope: "repo" }] });

Параметры необязательны: file, repo, scope: "repo". Без repo проверяется выбранный индекс, включая межрепозиторные файловые циклы; с repo — один участник. scope: "repo" выбирает циклы между репозиториями.

Цикл импорта — структурное свойство. Сам по себе он не доказывает ошибку выполнения.

dead ​

Найдите кандидатов на неиспользуемые объявления или проверьте отдельный символ.

js
dead({ queries: [{}] });
dead({ queries: [{ file: "a.js", symbol: "foo" }] });

Параметры необязательны: file, symbol, repo, more.

Перед удалением проверьте публичные экспорты, строковые регистрации, точки входа и динамические обращения. Отсутствие индексированных потребителей не является достаточным доказательством ненужности кода.

Продолжение ответа ​

Большие карточки ограничивают число показанных мест. Для следующей страницы копируйте команду page из ответа целиком; для перехода к точке — open.

Продолжение связано с параметрами запроса и версией индекса. Если сервер возвращает view-changed, выполните предложенный restart. Не объединяйте страницы разных публикаций.

Сначала вопрос, затем код

Для исследования обычно достаточно найти точку через find или map, закрыть неизвестную связь через callers или callees, затем прочитать найденные исходники. Полный обход всех инструментов для каждой задачи не требуется.
