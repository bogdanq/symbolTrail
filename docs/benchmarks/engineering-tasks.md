# Пять инженерных задач

<p class="st-lead">Новая функция, исправление ошибки, ревью, рефакторинг и проверка восстановления после сбоя в рабочем проекте.</p>

**5 задач × 3 инструмента = 15 запусков**. Агенты использовали SymbolTrail, CodeGraph или Graphify и работали в отдельных копиях одного снимка проекта. Они читали код, запускали команды и проверки, вносили изменения, если этого требовала задача.

## Общие результаты

Общую оценку считали как среднее по пяти задачам. Все 15 запусков завершены.

SymbolTrail и CodeGraph получили **97,67 / 100**, Graphify получил **100 / 100**. Оценивали качество выполнения задач. Точность парсера в эту оценку не входит.

## Задачи и результаты

Для каждой задачи указаны оценка, токены, действия, время и расчётная стоимость.

### 01. Скрытие тестовых файлов в поиске

Добавить переключатель, состояние которого сохраняется в URL. Он должен одинаково фильтровать файлы, текстовые совпадения и unused=prod. Проверялись пагинация, переходы назад/вперёд, незавершённые запросы и ссылки из прежней выдачи.

Все три решения получили **100 / 100** и прошли **14 из 14 независимых проверок**. Для проверки UI использовали React и happy-dom с мокированным HTTP. Реальное HTTP-поведение сервера проверяли отдельно.

<BenchmarkTable :table="data.tasks[0].table" />

### 02. Область поиска unused=prod

Воспроизвести и исправить сбои поиска: зависимость выдачи от порядка выбранных репозиториев и потерю ограничения по файлу. Через публичный HTTP-вход проверить объединение однотипных фильтров по OR и пересечение разных фильтров по AND.

Все три решения получили **100 / 100** и прошли **8 из 8 независимых проверок**, включая перестановку фильтров, пагинацию и одинаковые имена объявлений в разных областях.

<BenchmarkTable :table="data.tasks[1].table" />

### 03. Ревью пакетных запросов MCP и CLI

Проверить переход на массив queries: схемы, диспетчеризацию, порядок ответов, ошибки, продолжения и потребителей CLI. Задача требовала подтверждённых замечаний без исправления реализации.

Graphify обнаружил **P2-дефект кода завершения CLI**, который SymbolTrail и CodeGraph пропустили. Все три решения получили **100 / 100**.

<BenchmarkTable :table="data.tasks[2].table" />

### 04. Типизированная маршрутизация HTTP

Избавиться от необходимости одновременно поддерживать несколько перечней видов срезов и обработчиков. Сохранить адреса, параметры, значения по умолчанию, ответы и HTTP-статусы. Проверить сервер и потребителей интерфейса.

Все три решения получили **100 / 100** и прошли **171 из 171 независимой проверки** публичного поведения.

<BenchmarkTable :table="data.tasks[3].table" />

### 05. Восстановление после ошибки записи индекса

Проверить откат неудачной транзакции и следующее успешное обновление без перезапуска MCP. Отдельно проверить очередь watch: изменения, поступившие во время неудачной сборки, должны попасть в следующую обработку.

Все три решения выдержали **три повторения** и проверки отката и публикации. Только новый тест Graphify обнаруживал потерю события для файла, изменённого во время сбоя. В двух других решениях повторная постановка исходного пути маскировала этот дефект. Решения получили оценки **88,33 / 88,33 / 100**. Очередь проверяли управляемыми событиями. Реальные уведомления ОС не подтверждены из-за ограничения fs.watch / EMFILE в среде запуска.

## Как считали

**Оценка.** Решения оценивали по заранее заданным критериям и независимым проверкам. Для ревью использовали итоговую оценку из отчёта с корректировкой после завершения серии. Повторных запусков не было. Проверка того, обнаруживают ли новые тесты дефекты, не заменяет фактические результаты запусков.

**Токены и действия.** Вход включает весь нативный контекст модели и кэш. Кэш повторно не прибавляется. Выход включает всю генерацию. К действиям отнесены видимые shell, patch и MCP-вызовы. Вызов Graphify через CLI входит в shell, поэтому счётчик исследовательского MCP не охватывает все способы исследования. Одна shell-команда может объединять несколько операций.

**Стоимость.** Стоимость рассчитана как эквивалент API по ставкам, сохранённым в отчёте на **21 октября 2026 года**: за миллион токенов $2 за обычный вход, $0,10 за кэшированный вход и $10 за выход. Для расчётных кредитов использованы ставки 50 / 2,5 / 250 соответственно. Эти суммы не отражают фактических списаний с подписки или счёта. Расход координатора и вспомогательных запусков сюда не входит.

**Время.** Длительности пяти запусков суммировали. Агенты и фоновые проверки работали параллельно на одном компьютере, поэтому показатель не равен длительности всей серии и не является изолированным замером быстродействия.

У запусков были отдельные рабочие копии и контексты, но файловую систему полностью не изолировали. UI-проверки не были браузерными E2E.
