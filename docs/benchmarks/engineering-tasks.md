# Пять инженерных задач

<p class="st-lead">Новая функция, исправление ошибки, ревью, рефакторинг и проверка восстановления после сбоя — задачи в рабочем проекте.</p>

**5 задач × 3 инструмента = 15 запусков**. Агенты работали с SymbolTrail, CodeGraph или Graphify в отдельных рабочих копиях одного снимка проекта: читали код, запускали команды и проверки, вносили изменения там, где этого требовала задача.

## Общие результаты

Общая оценка — среднее по пяти задачам. Все 15 запусков завершены.

SymbolTrail и CodeGraph получили **97,67 / 100**, Graphify — **100 / 100**. Результат отражает качество выполненных задач, а не точность парсера.

## Задачи и результаты

Под каждой задачей — одна таблица с оценкой, токенами, действиями, временем и расчётной стоимостью.

### 01. Скрытие тестовых файлов в поиске

Добавить переключатель с сохранением состояния в URL и единым фильтром для файлов, текстовых совпадений и unused=prod. Проверялись пагинация, переходы назад/вперёд, незавершённые запросы и ссылки из прежней выдачи.

Все три решения получили **100 / 100** и прошли **14 из 14 независимых проверок**. UI проверялся через React и happy-dom с мокированным HTTP; реальное HTTP-поведение сервера проверялось отдельно.

<BenchmarkTable :table="data.tasks[0].table" />

### 02. Область поиска unused=prod

Воспроизвести и исправить зависимость выдачи от порядка выбранных репозиториев и потерю ограничения по файлу. Проверить объединение однотипных фильтров по OR и пересечение разных фильтров по AND через публичный HTTP-вход.

Все три решения получили **100 / 100** и прошли **8 из 8 независимых проверок**, включая перестановку фильтров, пагинацию и одинаковые имена объявлений в разных областях.

<BenchmarkTable :table="data.tasks[1].table" />

### 03. Ревью пакетных запросов MCP и CLI

Проверить переход на массив queries: схемы, диспетчеризацию, порядок ответов, ошибки, продолжения и потребителей CLI. Задача требовала подтверждённых замечаний без исправления реализации.

Graphify обнаружил **P2-дефект кода завершения CLI**, который SymbolTrail и CodeGraph пропустили. Оценка — **100 / 100 для всех трёх решений**.

<BenchmarkTable :table="data.tasks[2].table" />

### 04. Типизированная маршрутизация HTTP

Убрать необходимость синхронно поддерживать несколько перечней видов срезов и обработчиков. Сохранить адреса, параметры, значения по умолчанию, ответы и HTTP-статусы, проверив сервер и потребителей интерфейса.

Все три решения получили **100 / 100** и прошли **171 из 171 независимой проверки** публичного поведения.

<BenchmarkTable :table="data.tasks[3].table" />

### 05. Восстановление после ошибки записи индекса

Проверить откат неудачной транзакции и следующее успешное обновление без перезапуска MCP. Отдельно проверить очередь watch: изменения, поступившие во время неудачной сборки, должны попасть в следующую обработку.

Все три решения выдержали **три повторения** и проверки отката и публикации. Только новый тест Graphify обнаруживал потерю события для файла, изменённого во время сбоя; в двух других решениях повторная постановка исходного пути маскировала этот дефект. Оценки — **88,33 / 88,33 / 100**. Очередь проверялась управляемыми событиями; реальные уведомления ОС не подтверждены из-за ограничения fs.watch / EMFILE в среде запуска.

## Как считали

**Оценка.** Заранее заданные критерии и независимые проверки решений. Для ревью используется итоговая оценка из отчёта, скорректированная после завершения серии; повторных запусков не было. Проверка чувствительности новых тестов к дефектам не подменяет фактические результаты запусков.

**Токены и действия.** Вход — весь нативный контекст модели, включая кэш; кэш второй раз не прибавляется. Выход — вся генерация. Действия — видимые shell, patch и MCP-вызовы. Вызов Graphify через CLI входит в shell, поэтому счётчик исследовательского MCP не охватывает все способы исследования. Одна shell-команда может объединять несколько операций.

**Стоимость.** Это эквивалент API по ставкам, сохранённым в отчёте на **21 октября 2026 года**: за миллион токенов $2 за обычный вход, $0,10 за кэшированный вход и $10 за выход. Расчётные кредиты используют ставки 50 / 2,5 / 250 соответственно. Это не фактическое списание с подписки или счёта; расход координатора и вспомогательных запусков сюда не входит.

**Время.** Сумма длительностей пяти запусков. Агенты и фоновые проверки работали параллельно на одном компьютере, поэтому показатель не равен длительности всей серии и не является изолированным замером быстродействия.
