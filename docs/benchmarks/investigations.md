# Сквозное исследование кода

<p class="st-lead">От действия в интерфейсе до HTTP, SQL и индексных связей: как агент восстанавливает поведение проекта с разными инструментами.</p>

## Методология теста

Для проверки эффективности инструментов был проведен эксперимент по схеме **10 задач × 3 инструмента = 30 запусков**.

- **Объект исследования:** Единый снимок реального проекта из **635 исходных файлов**.
- **Участники:** AI-агенты, использующие **SymbolTrail**, **CodeGraph** или **Graphify**.
- **Цель:** Объяснить сложное сквозное поведение системы (от UI до базы данных) без внесения изменений в код.

## Общие результаты

Оценки качества ответов и полезности графа были усреднены по всем десяти задачам. Также суммировались затраты токенов, количество обращений к инструментам и общее время выполнения.

> 💡 **Что это значит?**
> Такой результат указывает на то, что агенты не полагаются слепо только на граф. Они используют его как карту для навигации, но **существенную часть сквозной цепочки** (логику внутри функций, условия, обработку данных) восстанавливают путем прямого **чтения исходного кода**. Граф помогает найти «где искать», а код отвечает на вопрос «как это работает».
