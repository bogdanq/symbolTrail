# Сквозное исследование кода

<p class="st-lead">Как агент исследует код проекта с помощью разных инструментов: от действий в интерфейсе до HTTP, SQL и связей в индексе.</p>

## Методология теста

Сводка включает **10 задач × 4 инструмента = 40 зачётных запусков**.

- Агенты работали на одном снимке проекта из 635 исходных файлов. Они исследовали код в режиме чтения.

## Общие результаты

CodeGraph израсходовал меньше всего суммарных входных и выходных токенов. У SymbolTrail меньше всего входных токенов без кэша, чтений исходников вне индексатора и повторно полученных строк. SymbolTrail и Graphify получили по 60 из 60 баллов.
