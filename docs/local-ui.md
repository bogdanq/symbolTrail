# Локальный интерфейс

<p class="st-lead">Исследуйте код и его связи прямо в браузере.</p>

У SymbolTrail есть локальный веб-интерфейс. Он работает с тем же индексом, что CLI и MCP, и позволяет изучать проект без подключения AI-агента.

## Что есть в UI

- **Индексы и репозитории** — каталог индексов с путём к базе, размером и датой. Внутри выбранного индекса можно посмотреть его репозитории и связи между ними.
- **Поиск с подсказками** — поиск символов с фильтрами по индексу, репозиторию и файлу. Результаты сгруппированы по файлам.
- **Карты и анализ зависимостей** — обзор на уровне репозиториев, файлов и вершин, просмотр циклов между файлами и репозиториями. В отдельном репозитории также доступны теплокарта, фильтр по пути и скрытие тестовых файлов.
- **Просмотр файлов** — исходный код с подсветкой, граф импортов и списки «Кто импортирует» и «Кого импортирует».
- **Карточки символов** — исходник, граф связей, места использования и количество входящих, исходящих и тестовых вызовов.
- **Коммиты и похожий код** — связанные с символом Git-коммиты и похожие по смыслу символы. Коммиты показываются при наличии Git-данных, а поиск похожего требует собранных векторов.

## Как запустить

Команды выполняются из **исходного репозитория инструмента**, где находятся `src` и `web/ui`. Подставьте путь к нему вместо `/path/to/symboltrail-source`, а исследуемый проект — вместо `/path/to/project`.

```sh
cd /path/to/symboltrail-source
npm install
npm --prefix web/ui install
npm run filegraph
npm run ui
```

Откройте локальный адрес, который Vite напечатает в терминале, и выберите нужный индекс. Для остановки сервера нажмите `Ctrl+C`.

::: tip Если индекс уже собран
Повторять установку зависимостей и сборку при каждом открытии UI не нужно. Достаточно выполнить `npm run ui`.
:::

## Обновление после правок

UI читает подготовленный индекс. Чтобы связи обновлялись после сохранения исходников, откройте второй терминал в том же репозитории и запустите:

```sh
npm run filegraph:watch
```

Подробнее о выборе индекса и режиме наблюдения — на странице [«Индексация»](/indexing).
