# Быстрый старт

<p class="st-lead">От исходников проекта до первого запроса к графу.</p>

## Подготовка

Чтобы запустить SymbolTrail из исходников, нужны Node.js 20.19+ и npm. Git нужен для истории изменений и анализа диффа. Для установки нативных зависимостей могут понадобиться системные инструменты сборки.

В командах ниже `/path/to/symboltrail-source` обозначает каталог исходников самого инструмента. Вместо `/path/to/project` подставьте проект, который хотите исследовать. Сайт документации запускается из отдельного репозитория.

## 1. Установите зависимости

Откройте исходный репозиторий SymbolTrail:

```sh
cd /path/to/symboltrail-source
npm install

cd /web/ui
npm install
```

Все следующие команды выполняются из этого каталога.

## 2. Постройте индекс

Передайте путь к исследуемому проекту:

```sh
npm run filegraph
```

Индекс появится в `.SymbolTrail/db/<имя-индекса>/index.sqlite` внутри исходного репозитория инструмента. Каталог `.SymbolTrail/index-roots.json` хранит состав индексов и выбранный `active`.

::: tip Уже есть другие индексы?
Новая сборка не обязательно меняет `active`. Проверьте его в каталоге индексов или задайте `FILEGRAPH_SET=<имя-индекса>` при запросе. Подробнее об этом в разделе [«Индексация»](/indexing#выбор-индекса).
:::

## 3. Выполните первый запрос

Проверьте подключение запросом циклов импортов. Для него не нужно заранее знать имена функций:

```sh
npm run mcp:cli -- 'cycles({ queries: [{}] })'
```

CLI вернёт текстовую карточку. Если выборка пуста, в выбранном индексе циклы не найдены. Это допустимый результат.

Чтобы найти конкретное объявление, подставьте его имя вместо `foo`:

```sh
npm run mcp:cli -- 'find({ queries: [{ name: "foo" }] })'
```

Доступные запросы и их ограничения описаны на странице [«Инструменты»](/tools).

## 4. Включите обновление

Если будете менять исходники, запустите наблюдение в отдельном терминале:

```sh
npm run filegraph:watch
```

Watch сначала строит индекс, затем обновляет его после сохранения файлов. Чтобы остановить watch, нажмите `Ctrl+C`.

## Открыть веб-интерфейс

Установите его зависимости и запустите локальный сервер:

```sh
npm --prefix web/ui install
npm run ui
```

Откройте адрес, который напечатает Vite. В интерфейсе можно выбрать индекс и репозиторий, найти код и открыть страницы файлов и символов. Интерфейс читает подготовленный индекс. Чтобы обновить связи, запустите watch или соберите индекс заново.

Обзор возможностей и пример размещения скриншота есть в разделе [«Локальный интерфейс»](/local-ui).

## Подключить агента

Чтобы работать из редактора, настройте [подключение MCP](/mcp). Запуск CLI не добавляет инструменты в агентский клиент.
