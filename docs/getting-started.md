# Быстрый старт

<p class="st-lead">От исходников проекта до первого запроса к графу за несколько минут.</p>

## Подготовка

Чтобы запустить SymbolTrail из исходников, вам понадобятся:

- **Node.js 20.19+** и **npm**
- **Git** — для работы с историей изменений и анализа диффов
- **Системные инструменты сборки** — могут понадобиться для установки нативных зависимостей

> 💡 **Обозначения в командах:**
>
> - `/path/to/symboltrail-source` — каталог с исходниками самого инструмента SymbolTrail
> - `/path/to/project` — проект, который вы хотите исследовать

## 1️⃣ Установите зависимости

Откройте терминал в исходном репозитории SymbolTrail и выполните:

```sh
cd /path/to/symboltrail-source
npm install

cd /web/ui
npm install
```

Все последующие команды выполняются из этого же каталога.

## 2️⃣ Постройте индекс

Передайте путь к исследуемому проекту:

```sh
npm run filegraph
```

После завершения индекс появится в:

```
.SymbolTrail/db/<имя-индекса>/index.sqlite
```

Состав индексов и выбранный активный индекс хранятся в файле:

```
.SymbolTrail/index-roots.json
```

::: tip Уже есть другие индексы?
Новая сборка не обязательно меняет `active` индекс. Проверьте его в каталоге индексов или явно задайте нужный через переменную окружения:

```sh
FILEGRAPH_SET=<имя-индекса>
```

Подробнее об управлении индексами читайте в разделе [«Индексация»](/indexing#выбор-индекса).
:::

## 3️⃣ Выполните первый запрос

Проверьте подключение простым запросом циклов импортов — для него не нужно заранее знать имена функций:

```sh
npm run mcp:cli -- 'cycles({ queries: [{}] })'
```

CLI вернёт текстовую карточку. Если выборка пуста, значит в выбранном индексе циклы не найдены. Это абсолютно нормальный результат.

Чтобы найти конкретное объявление, подставьте его имя вместо `foo`:

```sh
npm run mcp:cli -- 'find({ queries: [{ name: "foo" }] })'
```

Полный список доступных запросов и их ограничений описан на странице [«Инструменты»](/tools).

## 4️⃣ Включите автоматическое обновление

Если планируете менять исходники проекта, запустите наблюдение в отдельном терминале:

```sh
npm run filegraph:watch
```

Режим watch сначала построит индекс с нуля, а затем будет автоматически обновлять его после каждого сохранения файлов.

Чтобы остановить наблюдение, нажмите `Ctrl+C`.

## Открыть веб-интерфейс

Установите зависимости веб-интерфейса и запустите локальный сервер:

```sh
npm --prefix web/ui install
npm run ui
```

Откройте в браузере адрес, который напечатает Vite. В интерфейсе можно:

- Выбрать индекс и репозиторий
- Искать код и символы
- Открывать страницы файлов и символов

Интерфейс читает подготовленный индекс. Чтобы обновить связи, запустите watch или соберите индекс заново.

Подробный обзор возможностей и примеры интерфейса есть в разделе [«Локальный интерфейс»](/local-ui).

## Подключить агента

Чтобы работать с графом напрямую из редактора или агентского клиента, настройте [подключение MCP](/mcp).

> 💡 **Важно:** Запуск CLI не добавляет инструменты в агентский клиент — нужна отдельная настройка MCP.
