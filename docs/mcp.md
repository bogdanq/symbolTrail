# Подключение MCP

<p class="st-lead">Дайте AI-агенту доступ к связям вашего проекта.</p>

MCP-сервер SymbolTrail предоставляет восемь инструментов исследования кода. Он работает через stdio: клиент запускает процесс и получает текстовые карточки с найденными точками и связями.

## Перед подключением

Установите зависимости исходного репозитория SymbolTrail и [соберите индекс проекта](/getting-started). MCP читает подготовленную базу и сам не запускает индексацию.

## Настройка через установщик {#setup}

Из исходного репозитория инструмента выполните:

```sh
npm run setup -- --project /path/to/project --agent cursor / codex / gigacode
```

Установщик добавит MCP-сервер с именем `SymbolTrail` и скопирует навыки `graph-orchestrator` и `graph-bugfix` в проект. Исходники SymbolTrail останутся в своём каталоге.

При повторной настройке установщик переносит прежнее подключение на имя `SymbolTrail` и сохраняет дополнительные параметры сервера. После обновления перезапустите редактор или сессию агента, чтобы новое имя появилось в настройках MCP.

Поддержаны `cursor`, `codex` и `gigacode`. Можно выбрать несколько клиентов через запятую:

```sh
npm run setup -- --project /path/to/project --agent cursor / codex / gigacode
```

Конфигурация записывается в проекте:

- Cursor — `.cursor/mcp.json`.
- Codex — `.codex/config.toml`.
- Gigacode — `.gigacode/setting.json`.

Для доступных параметров установщика выполните `npm run setup -- --help`.

::: tip После установки
Перезапустите редактор или сессию агента. Если переместите исходный репозиторий SymbolTrail, повторите setup: конфигурация содержит пути к серверу и его зависимостям.
:::

## Ручной запуск

Точка запуска stdio-сервера из репозитория инструмента:

```sh
npm run mcp
```

Для JSON-клиента с поддержкой `cwd` можно использовать такую конфигурацию. Замените все пути на абсолютные пути к исходникам инструмента (после выполнения npm run setup пути должны подставиться автоматически):

```json
{
  "mcpServers": {
    "SymbolTrail": {
      "command": "node",
      "args": [
        "--import",
        "file:///path/to/symboltrail-source/node_modules/tsx/dist/loader.mjs",
        "/path/to/symboltrail-source/src/mcp-graph/index.ts"
      ],
      "cwd": "/path/to/symboltrail-source"
    }
  }
}
```

Если нужно выбрать конкретный индекс, передайте серверу `FILEGRAPH_SET` через настройки переменных окружения клиента. Без него используется `active` из каталога индексов.

## Проверка подключения

Убедитесь, что клиент видит `find`, `callers`, `callees`, `map`, `review`, `shape`, `cycles` и `dead`.

Пример запроса агенту:

> Найди объявление foo, покажи его потребителей и прочитай текущий код найденных мест. Отдели записанные связи от предположений о выполнении.

Замените `foo` именем из своего проекта. Формат прямых вызовов приведён в [справочнике инструментов](/tools).

## Навыки агента

**graph-orchestrator** направляет исследование: найти неизвестную связь, выбрать адреса и прочитать нужный код. **graph-bugfix** помогает связывать диагностику и исправление с проверкой наблюдаемого поведения.

Граф полезен для неизвестных переходов. Уже известное тело функции или явный импорт можно читать напрямую. Для текущих связей держите включённым [watch](/indexing#автоматическое-обновление).
