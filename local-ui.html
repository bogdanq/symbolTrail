Локальный интерфейс ​

Исследуйте код и его связи прямо в браузере, без необходимости подключать AI-агента.

Локальный веб-интерфейс SymbolTrail работает с тем же индексом, что и CLI, и MCP-сервер. Это отличный способ визуально изучить структуру проекта, проверить связи и найти нужный код самостоятельно.

Возможности интерфейса ​

  • 📂 Индексы и репозитории: Каталог всех собранных индексов с указанием пути к базе, её размера и даты обновления. Внутри индекса можно просмотреть список репозиториев и связи между ними.
  • 🔍 Умный поиск: Поиск символов с фильтрацией по индексу, репозиторию и файлу. Результаты автоматически группируются по файлам для удобства навигации.
  • 🗺️ Карты и анализ зависимостей: Визуальный обзор на уровне репозиториев, файлов и отдельных вершин. Включает просмотр циклов, теплокарты активности, фильтрацию по путям и возможность скрыть тестовые файлы.
  • 📄 Просмотр файлов: Подсвеченный исходный код, граф импортов, а также списки «Кто импортирует этот файл» и «Какие модули импортирует он сам».
  • 🧩 Карточки символов: Детальная информация: исходный код, граф связей, места использования, а также счетчики входящих, исходящих и тестовых вызовов.
  • 🔄 История и семантика: Просмотр связанных с символом Git-коммитов (при наличии Git-данных) и поиск семантически похожего кода (требует предварительно собранных векторов).

Как запустить ​

Все команды выполняются из исходного репозитория инструмента (где находятся папки src и web/ui).

💡 Обозначения в путях:

  • /path/to/symboltrail-source — путь к исходникам SymbolTrail.
  • /path/to/project — путь к исследуемому проекту.
sh
cd /path/to/symboltrail-source
npm install
npm --prefix web/ui install
npm run filegraph
npm run ui

Откройте в браузере локальный адрес, который выведет Vite в терминале, и выберите нужный индекс. Чтобы остановить сервер, нажмите Ctrl+C.

Если индекс уже собран

Если зависимости уже установлены и индекс построен, для запуска UI достаточно выполнить только npm run ui. Повторять установку и полную сборку каждый раз не нужно.

Обновление после изменений в коде ​

Интерфейс читает уже подготовленный индекс. Чтобы связи обновлялись автоматически после сохранения файлов в проекте, откройте второй терминал в том же репозитории и запустите режим наблюдения:

sh
npm run filegraph:watch

Подробнее о выборе индекса и настройке watch-режима читайте на странице «Индексация».

Обзор интерфейса ​

Нажмите на любой скриншот, чтобы открыть его в полном размере.

1. Каталог индексов ​

Стартовый экран показывает все доступные независимые индексы. В каждой карточке отображаются путь к базе данных, её размер и дата последнего обновления. Если база ещё не собрана, интерфейс выведет соответствующее уведомление.

2. Репозитории и межрепозиторные связи ​

Внутри выбранного индекса можно перейти к репозиториям, файлам, вершинам и циклам зависимостей. Здесь визуализированы циклы между репозиториями и представлена таблица с метаданными каждого участника индекса.

3. Детали репозитория ​

На карте отображается структура выбранного репозитория. Под ней расположен список файлов с показателями связей и быстрыми переходами к подробностям. В верхней панели доступны теплокарта, просмотр циклов и переключатель для скрытия тестовых файлов.

4. Просмотр файла ​

Страница файла содержит граф его импортов, подсвеченный исходный код и два навигационных списка: «Кто импортирует этот файл» и «Какие модули импортирует он сам». По этим спискам можно углубляться в цепочки зависимостей.

5. Карточка символа ​

Детальная карточка объединяет граф связей конкретного символа, его исходный код и количественные показатели вызовов. Ниже можно изучить конкретные места использования, связанные Git-коммиты и семантически похожий код.

6. Поиск и каталог ​

Задавайте область поиска с помощью тегов: индекс:, репо: и файл:. Пока запрос не введен, страница отображает обзор всех доступных индексов и входящих в них репозиториев.

7. Результаты поиска и места использования ​

Результаты поиска сгруппированы по файлам и содержат фрагменты исходного кода и экспорты. Выберите конкретный экспорт, чтобы посмотреть все места его использования. Любое место можно открыть в боковой панели с точной подсветкой нужной строки.
