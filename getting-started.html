Быстрый старт ​

От исходников проекта до первого запроса к графу.

Подготовка ​

Для запуска из исходников понадобятся Node.js 20.19+ и npm. Git нужен для данных об истории и анализа диффа. Установка нативных зависимостей может потребовать инструменты сборки вашей системы.

В командах ниже /path/to/symboltrail-source — каталог исходников самого инструмента, а /path/to/project — проект, который вы хотите исследовать. Репозиторий этого сайта документации запускается отдельно.

1. Установите зависимости ​

Откройте исходный репозиторий SymbolTrail:

sh
cd /path/to/symboltrail-source
npm install

cd /web/ui
npm install

Все следующие команды выполняются из этого каталога.

2. Постройте индекс ​

Передайте путь к исследуемому проекту:

sh
npm run filegraph

Индекс появится в .SymbolTrail/db/<имя-индекса>/index.sqlite внутри исходного репозитория инструмента. Каталог .SymbolTrail/index-roots.json хранит состав индексов и выбранный active.

Уже есть другие индексы?

Новая сборка не обязательно меняет active. Проверьте его в каталоге индексов или задайте FILEGRAPH_SET=<имя-индекса> при запросе. Подробности — в разделе «Индексация».

3. Выполните первый запрос ​

Для проверки подключения найдите циклы импортов — этот запрос не требует заранее знать имена функций:

sh
npm run mcp:cli -- 'cycles({ queries: [{}] })'

CLI вернёт текстовую карточку. Пустая выборка циклов — допустимый результат: для выбранного индекса циклы не найдены.

Чтобы найти конкретное объявление, подставьте его имя вместо foo:

sh
npm run mcp:cli -- 'find({ queries: [{ name: "foo" }] })'

Доступные запросы и их ограничения собраны на странице «Инструменты».

4. Включите обновление ​

Если будете менять исходники, запустите наблюдение в отдельном терминале:

sh
npm run filegraph:watch

Watch выполняет начальную сборку и обновляет индекс после сохранений. Для остановки нажмите Ctrl+C.

Открыть веб-интерфейс ​

Установите его зависимости и запустите локальный сервер:

sh
npm --prefix web/ui install
npm run ui

Откройте адрес, напечатанный Vite. Интерфейс позволяет выбрать индекс и репозиторий, искать код и переходить к страницам файлов и символов. Он читает подготовленный индекс; для актуальных связей нужен watch или новая сборка.

Краткий обзор возможностей и пример размещения скриншота — в разделе «Локальный интерфейс».

Подключить агента ​

Если нужен доступ из редактора, продолжите на странице «Подключение MCP». Сам по себе запуск CLI не добавляет инструменты в агентский клиент.
