Подключение MCP ​

Дайте AI-агенту прямой доступ к графу связей вашего проекта.

MCP-сервер SymbolTrail предоставляет 8 инструментов для исследования кода. Клиент запускает сервер и получает через stdio структурированные текстовые карточки с найденными точками и связями.

Перед подключением ​

  1. Установите зависимости в исходном репозитории SymbolTrail (npm install).
  2. Соберите индекс проекта.

💡 Важно: MCP-сервер только читает подготовленную базу данных. Он не запускает и не управляет процессом индексации.

Настройка через установщик ​

Самый простой способ интеграции, из корня репозитория SymbolTrail выполните:

sh
npm run setup -- --project /path/to/project --agent cursor

Что сделает установщик:

  1. Добавит MCP-сервер с именем SymbolTrail в конфигурацию вашего агента.
  2. Скопирует навыки (skills) graph-orchestrator и graph-bugfix в ваш проект.
  3. Исходники SymbolTrail при этом останутся в своём каталоге.

Интеграция с OpenSpec ​

Установщик также копирует файлы OpenSpec из каталога openspec репозитория SymbolTrail в папку openspec целевого проекта:

  • config.yaml с выбранной схемой graph-spec.
  • schemas/graph-spec/ с YAML-схемой и шаблонами: proposal, impact, specs, design и tasks.

Если OpenSpec не перенесён

При конфликте с существующими файлами или наличии openspec/config.yml установщик пропустит весь комплект OpenSpec (настройка MCP и навыков при этом продолжится).

В этом случае перенесите openspec/config.yaml и openspec/schemas/graph-spec/ вручную или попросите агента объединить их с настройками проекта. Установщик покажет источник, назначение и конфликтующие пути. Если файлы совпадают с поставляемыми, повторный перенос не требуется.

Поддержка нескольких агентов ​

Установщик поддерживает cursor, codex и gigacode. Чтобы настроить несколько клиентов сразу, перечислите их через запятую:

sh
npm run setup -- --project /path/to/project --agent cursor,codex,gigacode

Конфигурация сохраняется в стандартные файлы проекта:

АгентФайл конфигурации
Cursor.cursor/mcp.json
Codex.codex/config.toml
Gigacode.gigacode/setting.json

Полный список параметров установщика доступен по команде: npm run setup -- --help.

После установки

Перезапустите редактор или сессию агента. Если вы переместите исходный репозиторий SymbolTrail, повторите команду setup: конфигурация содержит жесткие пути к серверу и его зависимостям.

Ручной запуск ​

Если вы предпочитаете управлять конфигурацией вручную или ваш JSON-клиент поддерживает параметр cwd, запустите stdio-сервер из репозитория инструмента:

sh
npm run mcp

Используйте следующую конфигурацию для клиента, заменив все пути на абсолютные к исходникам инструмента (после npm run setup они должны подставиться автоматически):

json
{
  "mcpServers": {
    "SymbolTrail": {
      "command": "node",
      "args": [
        "--import",
        "file:///path/to/symboltrail-source/node_modules/tsx/dist/loader.mjs",
        "/path/to/symboltrail-source/src/mcp-graph/index.ts"
      ],
      "cwd": "/path/to/symboltrail-source"
    }
  }
}

Выбор индекса: Чтобы сервер использовал конкретный индекс, передайте переменную окружения FILEGRAPH_SET в настройках клиента. Без неё сервер по умолчанию использует active индекс из каталога .SymbolTrail.

Проверка подключения ​

Убедитесь, что ваш клиент видит все 8 инструментов SymbolTrail: find, callers, callees, map, review, shape, cycles и dead.

Пример запроса агенту для проверки:

Найди объявление foo, покажи его потребителей и прочитай текущий код найденных мест. Отдели записанные связи от предположений о выполнении.

(Замените foo на реальное имя из вашего проекта. Формат прямых вызовов инструментов описан в справочнике инструментов).

Навыки агента (Skills) ​

Для максимальной эффективности используйте встроенные навыки:

  • 🎻 graph-orchestrator: помогает агенту находить неизвестные связи, выбирать правильные адреса и читать нужный код в правильном порядке.
  • 🐛 graph-bugfix: помогает связать диагностику проблемы и её исправление с проверкой наблюдаемого поведения в графе.

Чтобы связи в графе всегда были актуальными, держите включённым режим автоматического обновления watch.
